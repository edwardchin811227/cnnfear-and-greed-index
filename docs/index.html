怎麼看這張圖

  • 黑線是 CNN Fear & Greed Index 每日收盤值（0 = 極度恐懼，100 = 極度貪婪）。
  • 藍虛線是 252 個交易日（≈1 年）移動平均，代表這段時間的「情緒基準線」。
  • 綠色帶是均值 +1σ / +2σ / +3σ，紅色帶是均值 −1σ / −2σ / −3σ。指數落在帶內＝正常波動；跑出 ±2σ 外＝統計上的異常情緒。
  • 下圖 Z-Score 把上面那條線標準化：Z =（今日值 − 252日均值）÷ 252日標準差。Z 為正＝偏貪婪，Z 為負＝偏恐懼。±2σ 以外的柱子是歷史上真正極端的時刻。
  • 要留意的解讀陷阱：指數「35 分、標籤寫恐懼」不等於統計上極端。要同時看 Z-Score —— Z 只有 −0.7σ 的話，那只是溫和偏離，離 −2σ 的極端還很遠。
